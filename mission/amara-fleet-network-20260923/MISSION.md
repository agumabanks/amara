Finally turn de-identified operational evidence into tested, versioned improvements shared across compatible devices. Do not let devices copy another shop's private memory or execute unreviewed downloaded code.

## Scope and constraints

This handoff is a phased implementation specification, not authorization to claim features already work. This planning pass changed mission documents only; it exported diagnostic journals and queried aggregate backend data. It did not publish, message, pair, change permissions, install an APK, or deploy backend features.

Polish existing components. Do not create a second worker scheduler, identity store, activity ledger, or dashboard application when the existing one can be extended. Owner Off, shop binding, channel selection, consent, quiet hours and uncertain-dispatch protection remain authoritative. A failing task is isolated; its history is retained.

The new platform-specific content direction supersedes the 20 September mission's TikTok-video-and-sound reuse requirement for this proposed work. Old publications and queue entries remain auditable. Do not reset dedupe keys to replay them.
